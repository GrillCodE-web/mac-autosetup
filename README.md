# MacForge

**One-shot macOS setup & hardening** — от чистой системы до боевой машины за один прогон.
Учётка, защита, приложения, FileVault, шифрованный том VeraCrypt с данными, самопроверка.

![macOS](https://img.shields.io/badge/macOS-14–15%20·%2026%20·%2027-black) ![bash](https://img.shields.io/badge/bash-3.2%2B-green) ![license](https://img.shields.io/badge/license-private-red) ![version](https://img.shields.io/badge/version-13.1-blue)

## Запуск — одна строка из Терминала

```bash
curl -fsSL https://raw.githubusercontent.com/GrillCodE-web/mac-autosetup/main/MacForge.command -o /tmp/MacForge.command && bash /tmp/MacForge.command
```

Аудит диска (read-only, ничего не меняет):

```bash
curl -fsSL https://raw.githubusercontent.com/GrillCodE-web/mac-autosetup/main/DiskAudit.command -o /tmp/DiskAudit.command && bash /tmp/DiskAudit.command
```

Скачивается в `/tmp`, запускается сразу, после перезагрузки чистится сам.
Не `curl | bash`, а скачать-и-запустить: скрипту нужен живой терминальный ввод (вопросы, пароли).

> Репозиторий публичный — ссылки работают без токена. Сделаешь приватным → raw вернёт 404, копируй с флешки.

## Что делает MacForge

- **5 вопросов** — учётка, пароль админа, диск уже зашифрован?, Wi-Fi, доп. программы (MailMate / qTox / Excel). Всё остальное молча.
- **Учётка** — отдельная рабочая без прав админа (каждый шаг dscl проверяется).
- **Харднинг с верификацией** — блокировка сразу, брандмауэр+stealth, глушатся SSH / экран / ARD / Remote Apple Events / принтеры / быстрое переключение, выкл AirDrop / Handoff / геолокация (по STIG: ключ + перезапуск locationd + проверка от его имени) / аналитика (с перезапуском adprivacyd) / Siri / подсказки Spotlight, скрыты «недавние» в Dock, Finder показывает ВСЕ расширения, иконки внешних дисков скрыты, проверены Gatekeeper/SIP, время с time.apple.com.
- **Wi-Fi** — удалить насовсем (только кабель) / выключить радио (с фолбэком `ifconfig down` на Tahoe) / не трогать.
- **Bluetooth** — открывается панель (без сторонних утилит); выключать, только если нет беспроводных клавы/мыши.
- **Приложения** — Telegram, Sublime Text, Linken Sphere 2, Tukan (+ по выбору MailMate, qTox, Excel). Прогресс-бар, 3 попытки, каждая установка проверяется.
- **Текстовые расширения → Sublime** — прямая запись в LaunchServices secure plist (все расширения из конфига), с проверкой каждого.
- **FileVault** — включается через `-inputplist` (пароль не на экране, не в файле, не в ps). Ключ восстановления не показывается и не сохраняется.
- **Секретный диск — только GUI VeraCrypt** — пароль диска скрипт не спрашивает, не видит, не хранит. Существующий диск не стирается. На томе выкл Spotlight + исключение из Time Machine.
- **Данные приложений на диске** — опознаются по СОДЕРЖИМОМУ (имена папок не важны). Симлинки; диск отключён — на Mac ноль пользовательских файлов. Проверка свободного места перед переносом.
- **Клавиатура** — ABC + Русская, переключение Ctrl+Space (работает на PC-клавиатурах без Option/Cmd). Часовой пояс — один раз по IP.
- **Отказоустойчивость** — лок от двойного запуска, отметки фаз в /tmp (упал → продолжил с места падения), честный `--dry-run` (план без единой мутации), конфиг переживает падение.
- **UX** — живой прогресс внутри фаз, звуки (Glass = важное, Pop = конец фазы), замер скорости канала, тайминг каждой фазы + итоговая сводка, автообновление скрипта с GitHub.
- **Следов нет** — ничего не логируется; в конце чистятся загрузки инсталляторов, история Терминала и «Недавние» в Finder.

## Самопроверка

В конце — встроенная таблица: ссылки приложений, FileVault, брандмауэр, VeraCrypt, свободное место тома. Всё зелёное = готово. Красное — следуй подсказке или шли скрин.

## Требования

- macOS 14–15 (Sonoma / Sequoia), 26 (Tahoe) или 27 (Golden Gate), только Apple Silicon. Ventura (13) не поддерживается — обновлений безопасности для неё больше нет
- Интернет по кабелю; VPN на роутере/Raspberry Pi — по желанию
- Внешний диск/флешка под VeraCrypt (VeraCrypt и FUSE-T ставятся скриптом)

## Главное правило

Ничего не хранить в системе Mac и на Рабочем столе — все файлы только на подключённом
секретном диске. Что попало в систему, можно восстановить даже после удаления.
Отключил диск — на Mac не должно остаться ни одного файла.

## План без изменений

```bash
bash MacForge.command --dry-run
```
