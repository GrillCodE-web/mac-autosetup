# MacForge

**Автонастройка и защита macOS за один запуск.** От чистой системы до рабочего Mac:
защита, приложения, FileVault, зашифрованный диск VeraCrypt с твоими данными и проверка в конце.
Нужно ответить на 6 вопросов и ввести пароль — остальное скрипт делает сам.

## Запуск — одна строка

Открой **Терминал** (Cmd+Пробел → «Терминал» → Enter), вставь и нажми Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/GrillCodE-web/mac-autosetup/main/MacForge.command -o /tmp/MacForge.command && bash /tmp/MacForge.command
```

Дальше читай экран и делай, что написано.

- Файл скачивается в `/tmp` (после перезагрузки сам пропадёт).
- Хочешь сначала посмотреть, что скрипт собирается сделать, ничего не меняя? Добавь `--dry-run`:
  `bash /tmp/MacForge.command --dry-run`
- Переустанавливаешь Mac с нуля? Сначала прочитай **[REINSTALL_GUIDE.md](REINSTALL_GUIDE.md)** — пошаговая инструкция от стирания диска до ежедневной работы.

## Что понадобится

- Mac на **Apple Silicon** (M1, M2, M3, M4). Intel не поддерживается.
- **macOS 14–15, 26 или 27.** Проверено на 27.2.
- Интернет **по кабелю**. Wi-Fi скрипт удаляет из системы сам и никогда не спрашивает про него.
- Внешний диск под секретные данные (VeraCrypt и FUSE-T скрипт ставит сам).

|---|---|---|
| Telegram | мессенджер | всегда |
| Sublime Text | текстовый редактор | всегда |
| Linken Sphere | браузер | всегда |
| Microsoft Excel | таблицы | всегда |
| VeraCrypt | шифрование секретного диска | всегда |
| FUSE-T | нужен VeraCrypt для работы с диском | всегда |

| qTox | мессенджер Tox | по запросу, буква **Q** |

## Шесть вопросов в начале

1. Создать отдельную рабочую учётку без прав админа?
2. Пароль текущего админа (нужен для настройки; в конце стирается из памяти).
3. Секретный диск уже зашифрован VeraCrypt? («да» по умолчанию — стереть его случайно нельзя.)
4. Какие доп. программы поставить: **M** — MailMate, **Q** — qTox (буквы подряд, `0` — ничего).
5. Через сколько гасить экран.
6. Через сколько автовыход из системы.

## Что делает скрипт

| Этап | Что происходит |
|---|---|
| 1. Учётка | Создаёт обычную учётку (если выбрал), каждый шаг проверяется |
| 2. Защита | Около 20 пунктов, каждый перечитывается после записи |
| 3. Приложения | Скачивание с прогресс-баром, 3 попытки, проверка каждой установки |
| 4. FileVault | Включение без показа пароля на экране |
| 5. Секретный диск | Только окно VeraCrypt: пароль диска скрипт не видит |
| 6. Данные | Данные приложений переезжают на диск, в системе остаются ссылки |

В конце — таблица самопроверки: всё зелёное = готово.

### Защита

- Блокировка экрана сразу, брандмауэр и режим невидимки
- Выключены: SSH, общий экран, удалённое управление, AirDrop, Handoff, Siri, подсказки Spotlight, геолокация, аналитика и рекламный идентификатор
- Гость выключен, на экране входа нет кнопки «Выключить» и подсказки пароля
- В Finder видны расширения файлов, внешние диски скрыты с Рабочего стола
- Раскладка только **ABC (US)**, язык и регион **США**, часовой пояс **Нью-Йорк**
- Wi-Fi удаляется из системы

### Данные и диск

- Пароль диска вводится только в окне VeraCrypt — скрипт его не знает.
- Существующий диск не стирается.
- Данные приложений опознаются **по содержимому**, а не по имени папки.
- Перенос безопасный: копия → сверка → ссылка → откат при любой ошибке.
- Битые ссылки от старых версий скрипта убираются сами.

### Если что-то пошло не так

- Закрылось окно или всё упало — запусти скрипт ещё раз, завершённые этапы он пропустит.
- Защита от двойного запуска, сверка диска перед переносом данных.
- Файлы-следы не создаются: логов нет, всё видно только на экране.

## Модель безопасности

- **Логов нет принципиально** — любой файл с историей настройки восстанавливается с диска.
- **Ключ восстановления FileVault** показывается один раз в терминале и нигде не сохраняется.
- **Пароль админа** живёт только в памяти и стирается до самопроверки. Пароль новой учётки в системный журнал не попадает.
- **Чистка в конце:** временные файлы скрипта и история Терминала. Чужие файлы в Загрузках не трогаются.

## FAQ

**Скрипт упал посередине. Всё заново?**
Нет. Запусти ещё раз — он продолжит с места остановки.

**Без диска Telegram открывается пустым. Это поломка?**
Нет, так и задумано: данные живут только на секретном диске. Подключил диск в VeraCrypt — всё на месте.

**Linken Sphere при первом запуске просит обновиться.**
Так и должно быть: ставится версия с сайта и сама обновляется. Скрипт отдаёт приложение тебе, поэтому обновление проходит до конца. Если выскочила ошибка — пришли её текст.

**Версии приложений не свежие?**
Telegram, Excel, MailMate и qTox качаются по ссылкам «последняя версия». VeraCrypt, FUSE-T и Sublime Text обновляются правкой строк в начале `MacForge.command`.

## Главное правило

Ничего не хранить в системе Mac и на Рабочем столе — только на подключённом секретном диске.
Отключил диск — на Mac не остаётся ни одного файла.
