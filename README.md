# mac-autosetup

Набор скриптов и инструкций для автоматической настройки и харднинга Mac после
чистой переустановки macOS. Весь процесс — от стирания системы до подключенного
секретного диска с данными Telegram — автоматизирован: от человека требуется
только нажимать Enter и вводить пароли.

## Что в репозитории

| Файл | Назначение |
|------|-----------|
| `ЗАПУСТИТЬ.command` | Главный скрипт автонастройки: учетная запись, харднинг системы, установка приложений, FileVault, шифрование и подключение диска VeraCrypt, перенос данных приложений, автообновления |
| `ПРОВЕРИТЬ.command` | Проверка после настройки: сам прогоняет все параметры и выдаёт зелёный/красный список с итоговым вердиктом и процентом; заодно смотрит, есть ли обновления macOS, и напоминает поставить их вручную |
| `МАНУАЛ_ПЕРЕУСТАНОВКА.md` | Пошаговый мануал по переустановке Mac с нуля (читать перед началом) |

## Что делает скрипт настройки

- **Учетная запись** — по желанию отдельная рабочая учетка без прав админа.
- **Харднинг** — пароль при блокировке сразу, автовыход и сон дисплея (таймауты
  спрашиваются при запуске, по умолчанию 30 и 5 минут), брандмауэр
  со stealth-режимом, выключенные AirDrop / Handoff / Bluetooth / геолокация /
  Siri / аналитика, пароль админа на общесистемные настройки.
- **Удалённый доступ глушится** — Общий экран, удалённое управление (ARD) и
  удалённый вход (SSH) выключаются насовсем (`launchctl disable` без `bootout` —
  выгрузка демона Общего экрана на свежих macOS роняет GUI-сессию, что выглядит
  как внезапная перезагрузка). Если настройка идёт через активный сеанс Общего
  экрана, он нарочно не обрывается — службы погаснут при финальной перезагрузке.
- **Без внезапных перезагрузок** — на время настройки отключаются автовыход,
  заставка и автовыстановка обновлений macOS (обновления больше не могут
  перезагрузить Mac посреди скачиваний); таймеры и ключи обновлений скрипт
  возвращает в самом конце.
- **Только кабель** — Wi-Fi полностью удаляется из сетевых служб, интернет
  исключительно по Ethernet (или Raspberry Pi в режиме USB-сетевой карты).
- **Шифрование** — включение FileVault (ключ переписать на бумажку) и внешний
  диск под VeraCrypt (AES, SHA-512). Существующий диск не стирается — только
  подключается.
- **Данные приложений на диске** — Telegram, Sublime Text, Tukan и другие. Если
  папки уже есть на диске (в любых своих подпапках), они остаются на месте — к ним
  просто делаются симлинки, ничего никуда не переносится. Диск отключен — на Mac
  ноль пользовательских файлов.
- **Программы по желанию** — MailMate (почта) и qTox (мессенджер Tox) ставятся по
  отдельному вопросу; их данные (`Application Support/MailMate` и `.../Tox`) тоже
  живут на зашифрованном диске через симлинки.
- **Клавиатура** — английская (U.S.) + русская раскладки и сочетание переключения
  (по умолчанию Ctrl+Space, на выбор Alt+Space, Cmd+Space или Caps Lock).
- **Двуязычный вывод** — все сообщения печатаются сразу на русском и английском.
- **Понятный терминал** — баннеры и линии подстраиваются под ширину окна, у
  каждой фазы штамп времени, ожидания идут со спиннером и счётчиком секунд,
  скачивание — с прогресс-баром, финал показывает общее время работы.
- **Следов не остаётся** — скрипт ничего не логирует и не оставляет после себя
  файлов; история Терминала чистится в конце.
- **Минимум ручной работы** — Bluetooth, «пароль сразу после заставки» и раскладки
  скрипт делает сам и **проверяет результат**; если macOS не дал сделать это из
  терминала, он открывает нужную панель настроек и ждет, пока не увидит нужное
  состояние. В конце остаются только пункты, которые автоматизировать нельзя.
- **Любой диск, любая структура** — ничего не захардкожено. Папка данных ищется по
  факту: `DataAPP`, `AppData`, папка с любым своим именем, где реально лежат данные
  приложений, или даже корень диска. Папка Telegram ищется по хвосту имени
  (`*keepcoder.Telegram`), потому что префикс у разных сборок отличается. Поэтому
  скрипт и проверка работают на чужом диске с другой раскладкой папок.

## Быстрый старт

Полная инструкция — в `МАНУАЛ_ПЕРЕУСТАНОВКА.md`. Коротко:

1. Стереть Mac и поставить чистую macOS (Части 1–3 мануала, при установке не
   подключаться к Wi-Fi, только кабель).
2. Скопировать эту папку на Mac, кликнуть `ЗАПУСТИТЬ.command` правой кнопкой —
   Открыть (или `bash ЗАПУСТИТЬ.command` из Терминала).
3. Следовать экрану: пароли, пару раз Enter, вставить диск по запросу.
4. Ответ **«да»** на вопрос «диск УЖЕ зашифрован VeraCrypt?» — и существующий
   диск не будет тронут.
5. Перезагрузиться и запустить `ПРОВЕРИТЬ.command`.

## Главное правило

Ничего не хранить в системе Mac и на Рабочем столе — все файлы только на
подключенном секретном диске. Что попало в систему, можно восстановить даже
после удаления. Отключил диск — на Mac не должно остаться ни одного файла.

## Требования

- macOS (проверялось на Apple Silicon, macOS Tahoe; на других версиях часть
  шагов может отличаться)
- Интернет по кабелю; VPN на роутере/Raspberry Pi — по желанию
- VeraCrypt (ставится скриптом автоматом)
