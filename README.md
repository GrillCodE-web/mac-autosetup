# mac-autosetup

Автоматическая настройка и харднинг Mac после чистой переустановки macOS.
Весь процесс — от создания учетки до подключенного секретного диска с данными —
автоматизирован: от человека требуется ответить на 5 вопросов и ввести пароли.

## Что в репозитории

| Файл | Назначение |
|------|-----------|
| `AutoInstaller.command` | Главный скрипт автонастройки (v12.6): учетная запись, харднинг, установка приложений, FileVault, диск VeraCrypt через GUI, перенос данных приложений на диск, встроенная самопроверка |
| `Preinstall_Audit.command` | Read-only аудит диска и системы: карта тома, опознанные данные (те же отпечатки, что у AutoInstaller), состояние симлинков, права Терминала, VeraCrypt/FUSE-T, гигиена тома |
| `МАНУАЛ_ПЕРЕУСТАНОВКА.md` | Пошаговый мануал по переустановке Mac с нуля (читать перед началом) |

Отдельного скрипта проверки больше нет: самопроверка встроена в конец
`AutoInstaller.command` и выводит итоговую таблицу (ссылки, FileVault,
брандмауэр, VeraCrypt).

## Что делает скрипт

- **5 вопросов на старте** — учетка, пароль админа, диск уже зашифрован?,
  режим Wi-Fi, доп. программы (MailMate / qTox / Excel). Всё остальное — молча.
- **Учетная запись** — по желанию отдельная рабочая учетка без прав админа
  (каждый шаг dscl проверяется).
- **Харднинг с верификацией каждого пункта** — пароль при блокировке сразу,
  брандмауэр + stealth, глушатся SSH / Общий экран / ARD / Remote Apple Events /
  общий доступ к принтерам / быстрое переключение пользователей, выключаются
  AirDrop / Handoff / геолокация / аналитика / Siri / подсказки Spotlight,
  скрываются «недавние» в Dock, Finder показывает ВСЕ расширения файлов,
  иконки внешних дисков скрыты с Рабочего стола, проверяются Gatekeeper и SIP,
  время синхронизируется с time.apple.com.
- **Wi-Fi по выбору** — удалить службу насовсем (только кабель), выключить
  радио или не трогать.
- **Bluetooth без сторонних утилит** — открывается панель настроек; выключать
  тумблер имеет смысл, только если нет беспроводных клавы/мыши.
- **Приложения** — Telegram, Sublime Text, Linken Sphere 2, Tukan (+ по выбору
  MailMate, qTox, Excel). Скачивание с прогресс-баром, 3 попытки на каждый
  пакет, живой прогресс фазы, каждая установка проверяется.
- **Текстовые расширения -> Sublime Text** — через прямую запись в
  LaunchServices secure plist (все расширения из конфига: txt, md, json, py…),
  с проверкой каждого расширения.
- **FileVault** — включается и проверяется; ключ восстановления НЕ
  показывается на экране и нигде не сохраняется.
- **Секретный диск — только через GUI VeraCrypt** — пароль диска скрипт не
  спрашивает, не видит и не хранит. Существующий диск не стирается. На томе
  выключается индексация Spotlight и исключается из Time Machine.
- **Данные приложений на диске** — опознаются по СОДЕРЖИМОМУ (имена папок не
  важны: app.ls, Sphere, Telegram_Data — найдутся все). К ним делаются
  симлинки; диск отключен — на Mac ноль пользовательских файлов.
- **Клавиатура** — ABC + Русская, переключение Ctrl+Space (работает на любой
  клавиатуре, включая PC без Option/Cmd). Часовой пояс — один раз по IP.
- **Защита от сбоев** — лок от двойного запуска, отметки фаз в /tmp
  (прерванный прогон продолжается с места падения), `--dry-run` печатает план
  без единого изменения, на время настройки отключены сон/автовыход/автоустановка
  обновлений (возвращаются в конце).
- **Удобство прогона** — живой прогресс внутри фаз, звуки (Glass = важное
  событие, Pop = конец фазы), замер скорости канала, тайминг каждой фазы и
  итоговая сводка времени, автообновление самого скрипта с GitHub.
- **Следов не остаётся** — скрипт ничего не логирует; в конце чистятся
  загрузки инсталляторов, история Терминала и «Недавние» в Finder.

## Быстрый старт

Полная инструкция — в `МАНУАЛ_ПЕРЕУСТАНОВКА.md`. Коротко:

1. Стереть Mac и поставить чистую macOS (Части 1–3 мануала, при установке не
   подключаться к Wi-Fi, только кабель).
2. Скопировать эту папку на Mac, кликнуть `AutoInstaller.command` правой
   кнопкой — Открыть (или `bash AutoInstaller.command` из Терминала).
3. Следовать экрану: 5 вопросов, пару раз Enter, вставить диск по запросу.
4. Ответ **«да»** на вопрос «диск УЖЕ зашифрован VeraCrypt?» — и существующий
   диск не будет тронут.
5. В конце скрипт сам покажет таблицу самопроверки — всё должно быть зелёным.

Перед боевым прогоном можно посмотреть план: `bash AutoInstaller.command --dry-run`.

## Главное правило

Ничего не хранить в системе Mac и на Рабочем столе — все файлы только на
подключенном секретном диске. Что попало в систему, можно восстановить даже
после удаления. Отключил диск — на Mac не должно остаться ни одного файла.

## Требования

- macOS 13–15 (Ventura / Sonoma / Sequoia) или 26 (Tahoe), Apple Silicon или Intel
- Интернет по кабелю; VPN на роутере/Raspberry Pi — по желанию
- Внешний диск/флешка под VeraCrypt (VeraCrypt и FUSE-T ставятся скриптом)
