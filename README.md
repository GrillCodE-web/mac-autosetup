# MacForge

**Автонастройка и харднинг macOS за один прогон** — от чистой системы до боевой машины:
учётка, защита, приложения, FileVault, зашифрованный том VeraCrypt с данными, самопроверка.
Человек отвечает на 5 вопросов — остальные ~40 минут скрипт работает сам.

## Запуск — одна строка

```bash
curl -fsSL https://raw.githubusercontent.com/GrillCodE-web/mac-autosetup/main/MacForge.command -o /tmp/MacForge.command && bash /tmp/MacForge.command
```

Скачивается в `/tmp` (после перезагрузки чистится сам), запускается сразу.
Не `curl | bash`, а скачать-и-запустить: скрипту нужен живой терминальный ввод (вопросы, пароли).

> Репозиторий публичный — ссылка работает без токена. Сделаешь приватным → raw вернёт 404, копируй файл с флешки.

**Переустанавливаешь Mac с нуля?** Сначала прочитай [REINSTALL_GUIDE.md](REINSTALL_GUIDE.md) — пошаговый мануал от стирания диска до ежедневной работы.

## Аудит диска — посмотреть, что где лежит (ничего не меняет)

```bash
curl -fsSL https://raw.githubusercontent.com/GrillCodE-web/mac-autosetup/main/DiskAudit.command -o /tmp/DiskAudit.command && bash /tmp/DiskAudit.command
```

Read-only: карта тома, опознанные данные приложений, симлинки, права, VeraCrypt, гигиена тома.
Паролей не спрашивает, ничего не устанавливает и **ничего не пишет в файлы** — отчёт живёт только в окне терминала: скопировал (Cmd+A, Cmd+C) → Enter → экран и прокрутка стираются.

## Как проходит настройка

**5 вопросов в начале** — больше скрипт ничего не спрашивает:

1. Создать отдельную рабочую учётку без прав админа?
2. Пароль текущего админа (для настройки системы; в конце обнуляется в памяти).
3. Секретный диск уже зашифрован VeraCrypt? («да» по умолчанию — стереть его нельзя случайно)
4. Wi-Fi: удалить насовсем / выключить радио / не трогать.
5. Доп. программы: **M**ailMate, **q**Tox, **E**xcel (буквы подряд, можно несколько).

Дальше — 6 фаз без участия человека:

| Фаза | Что происходит |
|------|----------------|
| 1. Учётка | Создание обычной учётки через `dscl`, каждый шаг с проверкой |
| 2. Базовая защита | Харднинг: ~20 пунктов, каждый перечитывается после записи |
| 3. Приложения | Скачивание с прогресс-баром, 3 попытки, проверка каждой установки |
| 4. FileVault | Включение через `-inputplist`: пароль не на экране, не в файле, не в ps |
| 5. Секретный диск | Только GUI VeraCrypt — пароль диска скрипт не видит вообще |
| 6. Данные | Данные приложений переезжают на диск, в системе остаются симлинки |

Финал — таблица самопроверки: всё зелёное = готово.

## Что делает под капотом

**Защита** (каждый пункт с верификацией)
- Блокировка паролем сразу после сна/заставки (`sysadminctl`, без GUI)
- Брандмауэр + stealth-режим; глушатся SSH, общий экран, ARD, Remote Apple Events, принтеры, быстрое переключение пользователей
- Геолокация — по STIG для macOS 26: ключ + перезапуск `locationd` + проверка глазами самого демона
- Аналитика/реклама — с перезапуском `adprivacyd`, чтобы демон не откатил значения
- AirDrop, Handoff, Siri, подсказки Spotlight в поиске — выкл
- Гость выключен, окно логина без подсказок пароля и без кнопки «Выключить»
- Finder показывает все расширения файлов; иконки внешних дисков скрыты с рабочего стола
- Gatekeeper и SIP — проверяются, что включены; время синхронизируется с time.apple.com

**Приложения**
- Telegram, Sublime Text, Linken Sphere 2, Tukan — всегда; MailMate, qTox, Excel — по выбору
- VeraCrypt 1.26.29 + FUSE-T 1.2.7 — для секретного диска
- Текстовые расширения (txt, md, json, py…) — сразу ассоциируются с Sublime через запись в LaunchServices secure plist, каждое с проверкой

**Секретный диск и данные**
- Пароль диска вводится только в окне VeraCrypt — скрипт его не спрашивает, не видит, не хранит
- Существующий диск не стирается; новый шифруется мастером VeraCrypt с подсказками на экране
- Данные приложений опознаются **по содержимому**, имена папок не важны
- Перенос атомарный: копия → сверка с оригиналом → симлинк → откат при любой ошибке; контроль свободного места до начала
- На томе выключается Spotlight и исключается из Time Machine

**Отказоустойчивость**
- Лок от двойного запуска; отметки фаз в `/tmp` — упал → продолжит с места падения
- При возобновлении сверяет UUID тома и диска — не перенесёт данные на чужую флешку
- `--dry-run` — честный план без единой мутации (даже конфиг не создаётся)
- Автопроверка новой версии скрипта на GitHub при запуске

**UX**
- Живой прогресс-бар внутри фаз, звуки (Glass = важное, Pop = конец фазы)
- Замер скорости канала, тайминг каждой фазы и итоговая сводка
- В конце — список того, что надо доделать руками (если что-то не встало само)

## Модель безопасности

- **Логов нет принципиально** — любой файл с историей настройки это след, который восстанавливается с диска. Всё видно только на экране.
- **Ключ восстановления FileVault** не показывается и не сохраняется (на macOS 26 система сама его больше не печатает).
- **Пароль админа** живёт только в переменной, обнуляется до самопроверки.
- **Финальная чистка:** инсталляторы из Загрузок, история Терминала, «Недавние» в Finder и меню приложений.
- Конфиг `autosetup.conf` рядом со скриптом создаётся сам, удаляется после успешного прогона.

## Требования

- **Mac на Apple Silicon** (M1/M2/M3/M4). Intel не поддерживается — скрипт остановится сразу.
- **macOS 14–15** (Sonoma / Sequoia), **26** (Tahoe) или **27** (Golden Gate). Ventura (13) не поддерживается — обновлений безопасности для неё больше нет.
- Интернет **по кабелю** (Ethernet или Raspberry Pi в режиме USB-сетевой карты); VPN на роутере — по желанию.
- Внешний диск/флешка под секретный том (VeraCrypt и FUSE-T ставит скрипт).

## FAQ

**Скрипт упал посередине / закрылось окно. Всё заново?**
Нет. Отметки завершённых фаз лежат в `/tmp` — следующий запуск продолжит с места падения. Все операции идемпотентны.

**Версии приложений в скрипте не свежие?**
Большинство ссылок динамические (Telegram, Tukan, MailMate, Excel, qTox через GitHub API latest) — всегда качается свежее. Установщик Sphere с официального сайта (1.9.9) после первого запуска сам обновляется до актуальной версии. FUSE-T и VeraCrypt обновляются правкой двух строк в `autosetup.conf`.

**Без диска Telegram открывается пустым — сломалось?**
Нет, это и есть смысл схемы: данные живут только на секретном диске. Смонтировал в VeraCrypt — всё вернулось.

**Нужен второй запуск после переустановки приложения?**
Просто запусти скрипт ещё раз — завершённые фазы он пропустит, недоделанное доделает.

## Главное правило

Ничего не хранить в системе Mac и на Рабочем столе — все файлы только на подключённом
секретном диске. Что попало в систему, можно восстановить даже после удаления.
Отключил диск — на Mac не должно остаться ни одного файла.
